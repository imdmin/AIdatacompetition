# 진동·전류 시계열 기반 프레스 유압펌프 이상 조기탐지 및 오경보 분석

제6회 K-인공지능 제조데이터 분석 경진대회 문제 ③에 참가한 팀의 작업물입니다.
KAMP 소성가공 예지보전 데이터셋으로 파인블랭킹 프레스 유압펌프의 이상을 탐지하고, 정상 운전 변화를 이상으로 판단하는 오경보를 분석했습니다.

- **데이터**: 상부 진동(AI0), 하부 진동(AI1), 전류(AI2), 10Hz 시계열
- **목표**: ① 진동·전류 시계열로 이상 탐지 ② 정상 운전 변화에 대한 오경보 감소 ③ 미탐지·오경보가 발생하는 조건 확인
- **최종 모델**: One-Class SVM 점수와 마할라노비스 거리를 가중합한 위험도로 판정하는 모델

---

## 작업 흐름

```
데이터 분석 → 데이터 전처리 → 모델 학습 → 모델 성과 비교 → 최종 모델 선정
```

### 1. 데이터 분석
- **측정 끊김**: 정상 데이터에서 1.5~16.6초의 끊김 598곳, 이상 데이터에서 20곳을 확인했습니다. 끊김은 보간하지 않고, 측정 간격 0.2초 이상에서 연속 구간을 나눴습니다(정상 599개, 이상 21개 구간).
- **전류 측정 해상도**: 이상 데이터의 전류값이 모두 1.192093의 정수배여서, 모든 전류값을 같은 단위로 반올림했습니다.
- **운전 상태 A·B**: 정상 데이터 후반부(00:59:54~01:11:31, 원본 인덱스 15,630~18,678)에서 진동이 작고 전류가 일정한 구간 88개가 연속으로 나타났습니다. 이를 운전 상태 B로, 나머지 정상을 상태 A로 구분했습니다.

### 2. 데이터 전처리
모델에 따라 전처리 경로를 둘로 나눴습니다.

| 항목 | 4개 모델 (IF · LSTM-AE · Feature AE · 1D-CNN AE) | One-Class SVM |
|---|---|---|
| 구간 분리 | 측정 간격 0.2초 이상에서 연속 구간 분리 | 시간 공백(0.5초 초과)·샘플링 간격 이상에서 burst 분리 |
| 윈도 | 16샘플(1.6초), 겹치지 않게 분할 | 17샘플, 이동 간격 4샘플로 겹쳐서 생성 |
| 모델 입력 | 특징 31개 중 선택한 5~8개, 또는 원신호 16×3 | 특징 3개 (V0_p2p, V1_flow, I_fent) |
| 데이터 분할 | 운전 상태 A·B별 시간순 60/20/20 (연속 구간 단위) | 원시 행 기준 시간순 70/15/15 (윈도 생성 전 분리) |
| 이상 데이터 | 검증·테스트에 50/50 | 검증·테스트에 50/50 |

- 16샘플 윈도는 전류 주기(약 16~17샘플), 큰 진동의 지속 시간(중앙값 9샘플), 데이터 손실을 근거로 8~30샘플을 비교해 정했습니다.
- 모든 모델은 정상 데이터만으로 학습했습니다.

### 3. 모델 학습

| 모델 | 입력 | 이상 점수 |
|---|---|---|
| Isolation Forest | 특징 7개(F1) / 5개(F2) | 고립 점수 |
| 소형 LSTM-Autoencoder | 원신호 16×3 | 복원 오차 |
| Feature Autoencoder | 특징 6~8개 | 복원 오차 |
| 1D-CNN Autoencoder | 원신호 16×3 | 복원 오차 |
| One-Class SVM | 특징 3개 | 경계로부터 거리 (+ 마할라노비스 거리) |

### 4. 모델 성과 비교

| 모델 | 평가 데이터 | F1-score | 정밀도 | 재현율 | 오경보 | 미탐지 |
|---|---|---|---|---|---|---|
| Isolation Forest (IF_F2) | 동일 조건 테스트 (정상 212, 이상 15) | 0.889 | 1.000 | 0.800 | 0/212 | 3/15 |
| 소형 LSTM-AE | 동일 조건 검증 (정상 208, 이상 13) | 0.917 | 1.000 | 0.846 | 0/208 | 2/13 |
| Feature AE | 동일 조건 테스트 (정상 212, 이상 15) | 0.929 | 1.000 | 0.867 | 0/212 | 2/15 |
| 1D-CNN AE | 개별 방식 (정상 157, 이상 28) | 0.945 | 0.963 | 0.929 | 1/157 | - |
| **One-Class SVM** | 17샘플·이동 4 테스트 (정상 458, 이상 39) | **0.975** | **0.951** | **1.000** | **2/458** | **0/39** |

- 동일 조건 = 같은 16샘플 윈도·같은 분할·같은 평가 모듈
- 상태를 구분해 평가한 3개 모델(IF·LSTM-AE·Feature AE)은 모두 상태 B 오경보 0이었습니다.
- One-Class SVM의 gamma·nu는 테스트 결과를 참고해 선택했으므로, 이 결과는 개발 단계의 재평가 결과입니다. 다른 모델의 16샘플·운전 상태별 분할 결과와 직접 순위를 비교하지 않습니다.

### 5. 최종 모델: One-Class SVM + 마할라노비스 거리

- One-Class SVM 점수와 마할라노비스 거리를 각각 정규화한 뒤 가중합한 위험도로 판정합니다. 가중치와 판정 기준선은 검증 데이터에서 F1이 최대가 되도록 정했습니다(정상 오경보율 1% 이하 조건).
- 위험도는 이상 여부를 판정하기 위한 지수이며, 고장 확률이 아닙니다.

**테스트 결과 (497윈도)**

| 지표 | 값 |
|---|---|
| 혼동행렬 (TN / FP / FN / TP) | 456 / 2 / 0 / 39 |
| 정밀도 | 0.9512 |
| 재현율 | 1.0000 |
| F1-score | 0.9750 |
| MCC | 0.9732 |
| FPR (위양성률) | 0.44% |
| ROC-AUC / PR-AUC | 1.0 / 1.0 |
| 윈도당 추론 시간 | 약 0.026 ms |

| 구역 | 윈도 수 |
|---|---|
| Normal (정상) | 414 (83.30%) |
| Caution_Warning (주의) | 42 (8.45%) |
| Critical_Anomaly (이상) | 41 (8.25%) |

- **오경보**: 303·304번 윈도에서 발생했으며, 하부 진동(AI1)의 저주파 전력 비율이 높은 경우였습니다. 어떤 정상 운전 변화 때문인지, 물리적 원인까지는 확정하지 않습니다.
- **미탐지**: 관찰되지 않았으므로, 미탐지가 발생하는 조건은 확정하지 않습니다.

## 실행 방법

### 환경
- Python 3
- 주요 라이브러리: pandas, numpy, scikit-learn, scipy, matplotlib, joblib, PyTorch(LSTM-AE)
- Feature AE의 패키지 버전은 `other models1_.../feature-autoencoder/requirements.txt`를 참고하세요.

### 실행 순서
```bash
# 1. 데이터 분석 (data 폴더 안에서 실행)
cd data
python 02_근거분석_간격과해상도.py
python "데이터 가공 명령1.py"        # 전류 해상도 맞춤 + 연속 구간 번호 부여(normal/outlier_segmented.csv)
python 03_근거분석_운전상태.py
python 04_근거분석_윈도길이.py
python 05_윈도_특징추출.py
python 06_특징분석.py
python 07_특징선택.py
cd ..

# 2. 전처리
python "데이터 전처리 파일/preprocess.py" data/press_data_normal.csv "데이터 전처리 파일/prep_normal.csv"
python "데이터 전처리 파일/preprocess.py" data/outlier_data.csv "데이터 전처리 파일/prep_outlier.csv"

# 3. 데이터 분할 → 특징 선택
python "데이터 분할 파일/08_데이터분할.py"
python "특징 선택 파일/09_특징선택.py"

# 4. 모델 학습·평가
python "모델 파일/10_IsolationForest.py"
python "LSTM_원신호 데이터 파일/11_원신호윈도.py"
python "모델 파일/12_LSTM_AE.py"
```

Feature AE, 1D-CNN AE, One-Class SVM은 각 폴더의 README를 참고하세요.
